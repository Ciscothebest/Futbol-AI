- No vas a actualizar el github al menos que te diga directamente que actualices el Github, por tanto solo vas a trabajar con los archivos en local de la carpeta FutbolAI Local.
- La carpeta local del proyecto a la que apunta el acceso directo del Escritorio es: `C:\Users\franc\OneDrive\Escritorio\Futbol AI Local` (`C:\Users\franc\OneDrive\Escritorio\FutbolAI Local.lnk`). Cada vez que realices un cambio en local, debes asegurarte de sincronizar/actualizar los archivos directamente en esa carpeta `C:\Users\franc\OneDrive\Escritorio\Futbol AI Local`.
- Cada vez que te diga que use la API de transfermarkt para extracción de información vas a usar la API de este repositorio https://github.com/felipeall/transfermarkt-api y vas a extraer la información pertinente solicitada de forma tacita sin interpretaciones.
